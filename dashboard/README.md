# Dashboard — Análise de Crédito e Prevenção à Inadimplência

## Sobre o dashboard

O dashboard foi desenvolvido no Google Looker Studio com o objetivo de apresentar visualmente os principais resultados da análise de inadimplência em cartões de crédito.

A ferramenta permite explorar indicadores, identificar padrões no comportamento financeiro dos clientes e compreender os fatores associados à inadimplência.

## Organização das páginas

# 1. Perfil e Visão Geral dos Clientes

Apresenta a distribuição de clientes adimplentes e inadimplentes, a taxa geral de inadimplência e informações sobre o perfil dos clientes.

# 2. Comportamento Financeiro e Inadimplência

Explora o histórico de pagamentos, os valores das faturas, os pagamentos realizados e as taxas de inadimplência por escolaridade.

# 3. Insights e Recomendações Estratégicas

Apresenta a interpretação dos resultados e recomendações para apoiar ações preventivas e melhorar a gestão de crédito.
